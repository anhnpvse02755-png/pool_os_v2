**Rule 4B — Product Validation Phase**

After completing Phase 7 (Coach AI Preview):

- **Build APK Preview** — releaseable artifact with full Vertical Slice
- **Product Validation** with real users
  - Real device UX testing
  - 5-10 user validation with North Star questions
  - Friction observation
- **Measure North Star** — validate that the complete workflow delivers user value
- **Decide next roadmap direction** (Branch A/B/C)

**Why:** Validating the full Vertical Slice end-to-end reveals whether the integrated workflow creates user value. Individual sprint validation cannot measure cross-sprint interactions.

**Branch Decisions after Phase 7 Validation:**

| Result | Action |
|--------|--------|
| North Star positive | Branch A: Continue Phase 8 roadmap |
| North Star neutral | Branch B: Improve weakest workflow |
| North Star negative | Branch C: Re-evaluate Vertical Slice scope |

**This does not invalidate Constitution — Rule 4 is deferred from Sprint-level to Milestone-level.**
