# POOL OS v2 - TESTER GUIDE
## Beta Testing Instructions

---

## 📱 INSTALLATION

### 1. Get APK
- **Debug APK:** `poolos_v2/build/app/outputs/flutter-apk/app-debug.apk`
- **Release APK:** `poolos_v2/build/app/outputs/flutter-apk/app-release.apk` (58MB - recommended)

### 2. Install
1. Copy APK to phone
2. Open file → Install
3. Enable "Unknown sources" if prompted
4. Open PoolOS

---

## 🎯 TESTER TASKS

### Task 1: Basic Navigation (10 min)
- [ ] Open app → See Dashboard
- [ ] Navigate 4 tabs: Home, Training, Play, Profile
- [ ] Go back to Home
- [ ] Open Settings
- [ ] Test Light/Dark theme toggle
- [ ] Test Language switch (EN/VI)

### Task 2: Create Profile (5 min)
- [ ] Create new player profile
- [ ] Enter name
- [ ] Select skill level (Beginner/Intermediate/Advanced)
- [ ] Save profile

### Task 3: Practice Drills (15 min)
- [ ] Go to Training Center
- [ ] Select a drill category
- [ ] Choose a drill
- [ ] Start practice session
- [ ] Complete 10 attempts
- [ ] Log results
- [ ] View progress

### Task 4: Record a Match (15 min)
- [ ] Go to Play tab
- [ ] Start new match
- [ ] Enter opponent name
- [ ] Record 3-5 racks
- [ ] Log results after each rack
- [ ] Complete match
- [ ] View match summary

### Task 5: Coach Recommendations (10 min)
- [ ] Go to Coach tab
- [ ] View today's recommendations
- [ ] Start recommended drill
- [ ] Complete drill
- [ ] Check Coach feedback

### Task 6: Equipment Management (10 min)
- [ ] Go to Profile → Equipment
- [ ] Add new cue
- [ ] Enter cue details
- [ ] Mark as "Playing" / "Break" cue
- [ ] Save

### Task 7: Export Test Data (5 min)
- [ ] Go to Settings
- [ ] Find Export option
- [ ] Export test logs
- [ ] Share via Zalo/Facebook/Messenger
