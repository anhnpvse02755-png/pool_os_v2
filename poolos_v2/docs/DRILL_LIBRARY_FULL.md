## SUCCESS CRITERIA

### For Each Drill:
```
Success Rate = Successful Attempts / Total Attempts

🥉 Level 1: 8-9/10 (80-90%)
🥉 Level 2: 7-8/10 (70-80%)
🥈 Level 3: 6-7/10 (60-70%)
🥈 Level 4: 4-5/10 (40-50%)
🥇 Level 5: 3-4/10 (30-40%)
🏆 Master: 2-3/10 (20-30%)
```

### Drill Completion:
```
Drill is "Mastered" when:
- 3 consecutive sessions at 80%+ success rate
- OR 10 total attempts at 85%+ success rate
```
