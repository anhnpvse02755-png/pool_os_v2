**Phase Development Conventions:**

- **Phase A:** Parity — replicate V1 functionality
- **Phase B:** Content — add product content/features
- **Phase C:** AI — implement AI capabilities
- **Phase D:** Competitive — competitive differentiation

**Phase 3 Constitution (6 Rules):**
1. Workflow
2. North Star
3. Definition of Done (DoD)
4. Rule 4A — Internal Build
5. Rule 4B — Product Validation
6. One Sprint One Workflow

**Rule 4A — Internal Build:** Continuous sprints từ Phase 3→7. Engineering Done là sprint gate.

**Rule 4B — Product Validation:** Validation chỉ xảy ra tại Phase 7 Milestone.

**Vertical Slice Roadmap:** Phase 3-7 đã LOCKED — tập trung vào Coach AI vertical slice.

**Why:** Convention này đảm bảo mỗi phase có deliverables rõ ràng và validation strategy.

**How to apply:** Khi planning sprint, xác định rõ phase target và rule nào áp dụng.
