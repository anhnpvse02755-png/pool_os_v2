Pool OS V2 vision: become the world's best billiards training app. Each
module must be evaluated against this vision, not against V1's surface.

**Why:** During the V1→V2 migration, comparing V1 to V2 surfaced only what
the team already had, not what users actually need. The roadmap below
re-defines success by vision, then layers V1 parity on top.

**How to apply:**
- New features or analyses start with "what would the world's best billiards
  training app include?", then check V1 last.
- All gap analyses should tag each item with a phase letter (A/B/C/D).
- Items that don't exist in V1 are still in scope.
