## IMPLEMENTATION

### Check Data Availability

```dart
bool get hasEnoughData {
  // Cần tối thiểu:
  // - 3 sessions tập, HOẶC
  // - 2 trận đấu với data
  return sessions.length >= 3 || matches.length >= 2;
}
```

### Coach State Logic

```dart
Widget build(BuildContext context) {
  final hasData = coachNotifier.hasEnoughData;
  
  return Column([
    _buildTodaySection(hasData),
    _buildWeaknessesSection(hasData),
    _buildRecommendedDrills(hasData),
  ]);
}
```

### Fallback Messages

```dart
String get noDataMessage => '''
Chưa đủ dữ liệu để AI phân tích.
```

## COACH SCREEN CHANGES

### File: `coach_screen.dart`

```dart
Widget _buildTodayRecommendation(BuildContext context, WidgetRef ref) {
  final coachState = ref.watch(coachStateProvider);
  final hasData = coachState.hasEnoughData;

  if (!hasData) {
    return _buildNoDataCard(
      title: 'Bắt đầu luyện tập',
      message: 'Chưa đủ dữ liệu để AI phân tích. '
               'Bạn cần tập ít nhất 3-5 bài tập hoặc ghi nhận 2-3 trận đấu.',
      actions: [
        ('Tập bài đầu tiên', () => context.push('/training/drills')),
        ('Ghi trận đấu', () => context.push('/play/recording')),
      ],
    );
  }
  
  // ... existing logic for hasData
}

Widget _buildWeaknessesSection(BuildContext context, WidgetRef ref) {
  final coachState = ref.watch(coachStateProvider);
  final hasData = coachState.hasEnoughData;

  if (!hasData) {
    return _buildNoDataCard(
      title: 'Điểm cần cải thiện',
      message: 'Chưa có dữ liệu để phân tích. '
               'Sau khi tập hoặc ghi trận đấu, '
               'AI sẽ đưa ra điểm cần cải thiện cụ thể.',
      actions: [
        ('Tập ngay', () => context.push('/training/drills')),
      ],
    );
  }
  
  // ... existing logic for hasData
}
```

## MESSAGES BY SCENARIO

### Scenario 1: User mới, chưa tập
```
⚠️  Chưa có dữ liệu để phân tích

Để AI Coach đưa ra lời khuyên cá nhân hóa, 
bạn cần:

1. Tập ít nhất 3-5 bài tập
2. Hoặc ghi nhận 2-3 trận đấu

Bạn có thể bắt đầu với bài tập nền tảng:
• Straight Pot - Đánh thẳng
• Stop Shot - Dừng bi
• Follow Shot - Bi đi tới
```

```
📊 Đang thu thập dữ liệu...
```
